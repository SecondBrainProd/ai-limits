Настройка

Три шага, около минуты

01

Поставьте виджет

Найдите AI Limits в Connect IQ Store и добавьте на часы.

02

Поставьте помощника на компьютер

На тот компьютер, где вы работаете в Claude Code. macOS или Linux с Homebrew:

brew install SecondBrainProd/tap/ailimits

Без Homebrew:

curl -fsSL https://raw.githubusercontent.com/SecondBrainProd/ai-limits/main/install.sh | sh

Windows: скачайте архив и распакуйте ailimits.exe. Программа пока не подписана, поэтому Windows может попросить подтверждение: «Подробнее», затем «Выполнить в любом случае».

03

Привяжите часы

Откройте AI Limits на часах — там появится код из шести букв. На компьютере выполните:

ailimits pair КОД
ailimits install-service

Вторая команда включает автозапуск: лимиты обновляются и после перезагрузки.

Нужен Claude Code с подпиской Pro или Max и телефон с Garmin Connect рядом: часы выходят в интернет через него.

Как устроено

Токен не покидает ваш компьютер

Помощник

Читает вход в Claude Code на вашем компьютере и раз в 5 минут спрашивает у Anthropic лимиты — так же, как сам Claude Code. Токен он не обновляет и не перезаписывает.

Посредник

Получает только числа: проценты, время сброса и названия моделей. Хранит последний снимок для каждого помощника и больше ничего.

Часы

Забирают снимок через телефон раз в 5 минут и сразу при открытии виджета. Если лимит сбросился, пока компьютер выключен, часы сами покажут 0%.

Вопросы

Перед установкой

Это официальное приложение Anthropic?

Нет. AI Limits — независимый проект с открытым кодом. Он читает те же данные о лимитах, что и сам Claude Code, через недокументированный адрес Anthropic. Если Anthropic изменит API, виджет может перестать работать.

Какие часы поддерживаются?

fēnix с 5-го по 9-й, включая версии S, X и Plus, fēnix E, fēnix Chronos, а также MARQ, MARQ 2 и MARQ 3 — всего 44 модели. Нужен Connect IQ 3.1 или новее, поэтому fēnix 3 не поддерживается.

Сильно ли садится батарея?

Виджет просыпается в фоне раз в 5 минут — чаще Connect IQ не разрешает — и делает один небольшой запрос через телефон.

Что, если компьютер выключен?

Часы хранят последний снимок и сами отсчитывают время до сброса. Данные старше 15 минут становятся серыми, а на полном экране видно, когда было последнее обновление.

Как отключиться?

Выполните ailimits unpair: посредник забудет этот компьютер, а часы покажут новый код. ailimits uninstall-service убирает автозапуск.

Политика конфиденциальности · обновлено 25 октября 2026

Приватность

Небольшой помощник на вашем компьютере читает вход в Claude Code локально, запрашивает у Anthropic лимиты и отправляет этому посреднику только числа: проценты, время сброса и названия моделей. Токен Claude уходит только в Anthropic — так же, как у самого Claude Code, — и никогда не попадает к посреднику.

Что хранит посредник

Последний снимок этих чисел для каждого помощника и случайные идентификаторы, которые связывают часы с помощником. Секреты хранятся в виде хешей SHA-256. Ни имён, ни почты, ни данных аккаунта.

IP-адреса

IP-адреса держатся в памяти около минуты, чтобы ограничивать частоту запросов. Журнала обращений нет. Если посредник ненадолго недоступен, веб-сервер может записать строку об ошибке с IP-адресом клиента.

Сроки

Непривязанные часы удаляются через сутки. Помощник, который молчит 30 дней, удаляется вместе со снимком. ailimits unpair удаляет его сразу.
