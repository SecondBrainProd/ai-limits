Setup

Three steps, about a minute

01

Install the widget

Find AI Limits in the Connect IQ Store and add it to your watch.

02

Install the helper on your computer

On the computer where you use Claude Code. macOS or Linux with Homebrew:

brew install SecondBrainProd/tap/ailimits

Without Homebrew:

curl -fsSL https://raw.githubusercontent.com/SecondBrainProd/ai-limits/main/install.sh | sh

Windows: download the zip and unpack the whole archive into one folder. It is not signed yet, so Windows may ask you to confirm: More info, then Run anyway.

03

Pair

Open AI Limits on the watch: it shows a six-character code. On the computer, run:

ailimits pair CODE
ailimits install-service

The second command keeps the limits updating after you log in.

You need Claude Code signed in with a Pro or Max subscription, and a phone with Garmin Connect nearby: the watch reaches the internet through it.

How it works

Your token stays on your computer

Helper

Reads your Claude Code sign-in locally and asks Anthropic for your usage every 5 minutes, exactly as Claude Code does. It never refreshes or rewrites the token.

Relay

Receives only the numbers: percentages, reset times and model labels. It keeps the latest snapshot for each helper and nothing else.

Watch

Fetches the snapshot every 5 minutes through your phone and right away when you open the widget. A window that resets while your computer is off drops to 0% on its own.

Questions

Before you install

Is this an official Anthropic app?

No. AI Limits is an independent open-source project. It reads the same usage numbers that Claude Code itself reads, through an endpoint Anthropic has not documented, so it may stop working if Anthropic changes its API.

Which watches are supported?

fēnix 5 to 9 with their S, X and Plus versions, fēnix E, fēnix Chronos, and MARQ, MARQ 2 and MARQ 3: 44 models in total. Connect IQ 3.1 or newer is required, so fēnix 3 is not supported.

Does it drain the battery?

The widget wakes up in the background once every 5 minutes, the minimum Connect IQ allows, and makes one small request through your phone.

What if my computer is off?

The watch keeps the last snapshot and counts the reset times down on its own. Data older than 15 minutes turns grey, and the full screen shows when it was last updated.

How do I disconnect?

Run ailimits unpair: the relay forgets this computer, and the watch shows a new code. ailimits uninstall-service removes the autostart.

Privacy policy · updated 25 October 2026

Privacy

A small helper on your computer reads your Claude Code sign-in locally, asks Anthropic for your usage limits, and sends only the numbers to this relay: percentages, reset times and model labels. Your Claude token is sent only to Anthropic, exactly as Claude Code itself does, and never to this relay.

What the relay keeps

The latest snapshot of those numbers for each helper, plus random identifiers that pair a watch with a helper. Secrets are stored as SHA-256 hashes. No names, no e-mail, no account data.

IP addresses

IP addresses are used in memory for about a minute to rate-limit requests. There is no access log. If the relay is briefly unavailable, the web server may record an error line that includes the client's IP address.

How long

Unpaired watches are deleted after a day. A helper that stays silent for 30 days is deleted together with its snapshot. ailimits unpair deletes it at once.
