AI Limits

Your Claude Code usage limits — the 5-hour window, the week and the per-model week — on your Garmin watch.

Get started

1. Install the AI Limits widget on your watch from the Connect IQ Store.

2. Install the helper on the computer where you use Claude Code:
brew install SecondBrainProd/tap/ailimits
or curl -fsSL https://raw.githubusercontent.com/SecondBrainProd/ai-limits/main/install.sh | sh
Windows: download the zip.

3. Open AI Limits on the watch, then run ailimits pair CODE and ailimits install-service.

Source code and details: github.com/SecondBrainProd/ai-limits.

Privacy

A small helper on your computer reads your Claude Code sign-in locally, asks Anthropic for your usage limits, and sends only the numbers here: percentages, reset times and model labels. Your Claude token is sent only to Anthropic, exactly as Claude Code itself does, and never to this relay.

This relay keeps only the latest snapshot of those numbers per helper, plus random identifiers that pair a watch with a helper. No names, no e-mail, no account data. IP addresses are used in memory for about a minute to rate-limit requests. There is no access log; if the relay is briefly unavailable, the web server may record an error line that includes the client's IP address. Unpaired watches are deleted after a day; a helper that stays silent for 30 days is deleted together with its snapshot.
